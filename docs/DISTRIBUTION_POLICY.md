# StardustFS 파일 저장 위치 정책

파일이 실제로 어디에 저장되는지를 예시로 설명한다.

핵심 한 줄: 파일 실체(암호문)는 그 파일을 만든 디바이스에만 있고, 다른 디바이스는
"어디에 있는지"만 안다(메타데이터). 필요할 때 가져온다.

## 케이스 1: 한 사람이 여러 PC를 쓸 때

PC-A와 PC-B는 같은 계정, 같은 열쇠(master_key)를 쓴다.

### 파일 A를 PC-A에서 만들면

- 파일 A(암호문)는 PC-A 디스크에만 저장된다.
- PC-B에는 "파일 A는 PC-A에 있다"는 메타데이터만 서버를 통해 전달된다.
- PC-B 화면에는 파일 A가 보이지만, 실체는 없다.

```
파일 A 실체:  [PC-A ✅]   [PC-B ❌ 목록만 보임]
```

### PC-B에서 파일 A를 열면(읽기)

- PC-B가 PC-A에서 가져온다. 연결은 3단계로 시도하고 앞이 안 되면 다음으로 내려간다.
  1. 직접 TCP (같은 LAN이나 포트 도달 가능 시 가장 빠름)
  2. 홀펀칭 UDP (대부분의 가정용 NAT를 라우터 설정 없이 통과)
  3. 서버 릴레이 (홀펀칭마저 안 되는 symmetric NAT/CGNAT일 때 최후 수단)
- 같은 열쇠라서 PC-B가 받은 암호문을 바로 풀 수 있다.

```
PC-B  ── ① 직접 TCP ──▶  PC-A
PC-B  ── ② 홀펀칭 UDP ─▶  PC-A       (①이 안 되면)
PC-B  ── ③ 서버 릴레이 ▶  PC-A       (②도 안 되면, 서버는 암호문만 중계)
```

상세는 [TRANSPORT.md](./TRANSPORT.md) 참조.

### PC-B에서 파일 A를 고치면(쓰기)

- 파일 A가 PC-B 디스크에 새로 저장되고, 소유권이 PC-B로 넘어온다.
- PC-A에 있던 원래 파일 A는 쓸모없어져서 나중에 자동 삭제된다(정리).
- 파일은 여전히 1개로 보이고, 내용만 새 버전이다.

```
고치기 전:  파일 A 실체 = [PC-A]
고친 후:    파일 A 실체 = [PC-B]   (PC-A의 옛것은 자동 삭제)
```

## 케이스 2: 여러 사람이 각자 PC를 쓸 때

User A와 User B는 서로 다른 계정, 서로 다른 열쇠를 쓴다.

- User A의 파일은 User A의 PC들에만 오간다(위 케이스 1과 동일).
- User B의 파일은 User B의 PC들에만 오간다.
- 서로 다른 계정끼리는 파일을 그냥 공유하지 않는다(정책상 금지).
- 예외: 백업 목적의 암호화된 조각(패리티)만 남의 PC에 맡길 수 있다. 맡아도 상대는
  내용을 못 본다(암호문). — 이 기능은 아직 계획 단계(MVP3).

```
User A 파일  ↔  User A의 PC들        ✅ 평문 그대로 오감
User B 파일  ↔  User B의 PC들        ✅ 평문 그대로 오감
User A 파일  ─▶  User B의 PC          🔒 암호화된 백업 조각만 (계획, 내용 못 봄)
User A 파일  ✗   User B와 평문 공유    ❌ 금지
```

## 서버의 역할

서버는 파일 실체를 저장하지 않는다. 서버가 하는 일:

- 로그인 확인
- "누구의 어떤 파일이 어느 PC에 있는지" 메타데이터를 보관(단, 내용은 암호문이라 못 봄)
- PC끼리 직접 연결이 안 될 때 중계(릴레이)
- 변경이 생기면 다른 PC에 즉시 알림

서버는 어느 파일의 내용도 볼 수 없다(zero-knowledge).

## 요약 표

| 상황 | 파일 실체 위치 | 서버 |
| --- | --- | --- |
| PC-A가 만든 파일 | PC-A에만 | 위치 메타데이터만(암호문) |
| PC-B가 그 파일 읽기 | PC-A에서 가져옴(직접 TCP→홀펀칭 UDP→릴레이) | 필요 시 중계 |
| PC-B가 그 파일 수정 | PC-B로 이전, PC-A 원본 삭제 | 변경 알림 |
| 다른 계정 파일 | 각자 PC에만 | 평문 공유 금지, 암호 백업 조각만(계획) |
